# make-knowledge-cards

`make-knowledge-cards` 是一个面向 AI 助手的 Skill，用于把文章中的重要内容整理成简洁、忠于原文的知识卡片。它帮助读者从长文中提取可复习的要点，同时避免重复、拆分同一知识点或补写来源没有的信息。

## 主要功能

- 接受用户直接粘贴的文章，或本地 Markdown（`.md`）和纯文本（`.txt`）文件。
- 提取重要且彼此不同的知识点；每张卡片只讲一个知识点，并合并重复内容。
- 每张卡片包含标题、核心知识、简明解释，以及原文支持的例子或自测问题。
- 原文足够时生成 5–8 张；信息不足时生成更少，不为达到数量而编造内容。
- 不支持网页抓取、PDF、Anki 导出或图形界面。

## 安装

本项目是 Skill 指令，不是独立应用；无需安装依赖或运行服务。

1. 将仓库中的 `skills/make-knowledge-cards` 文件夹复制到你所用 AI 助手支持的 Skills 目录。
2. 按该助手的说明启用或重新加载 Skill。

支持的 Skills 目录因 AI 助手而异；请以所用平台的安装说明为准。若平台支持从当前项目加载 Skills，也可以直接使用项目中的该目录。

## 使用方法

启用后，直接粘贴文章并要求“把这篇文章整理成知识卡片”，或提供本地 `.md` / `.txt` 文件并提出同样的请求。若文件不可读取或格式不受支持，请改为粘贴文本或提供支持的文件。

## 输入与输出示例

**输入**

> 检索练习是主动从记忆中提取信息，而不是重读材料。研究发现，自我测试可以改善长期记忆。把练习分散到多个时段，通常也比一次集中练习更有利于保持记忆。

**输出**

### 1. 检索练习强调主动回忆
- **核心知识：** 检索练习是主动从记忆中提取信息，而不是重读材料。
- **简明解释：** 练习时先尝试回忆所学内容，而非再次阅读。
- **例子或自测：** 根据原文，检索练习与重读材料有什么区别？

### 2. 分散练习通常更有利于记忆保持
- **核心知识：** 把练习分散到多个时段，通常比一次集中练习更有利于保持记忆。
- **简明解释：** 与把练习全部放在一次完成相比，原文更支持分多个时段练习。
- **例子或自测：** 根据原文，哪种练习安排通常更有利于保持记忆？

这段示例原文只支持两个独立要点，因此输出两张卡片，不为凑足 5 张而补充内容。
